# Phase 5 — Dashboard

## 1. Objective

The objective of Phase 5 is to provide a frontend dashboard for monitoring the LightX-IDS system, industrial sensor information, attack activity, IDS predictions, dataset analytics, and system logs.

---

## 2. Frontend Technology

The frontend is implemented using:

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- React Icons
- Chart.js / Recharts

---

## 3. Dashboard Structure

The frontend contains the following major pages:

- Dashboard
- Sensors
- Attack Monitoring
- IDS Prediction
- Dataset Analytics
- System Logs
- Settings
- Login

---

## 4. Dashboard

The Dashboard provides the main interface for viewing the LightX-IDS system.

The frontend includes reusable dashboard components such as:

- `TemperatureChart`
- `PressureChart`

## 12. Routing

The frontend uses React Router for page navigation.

The implemented routes are:

| Route | Page |
|---|---|
| `/` | Dashboard |
| `/sensors` | Sensors |
| `/attacks` | Attack Monitoring |
| `/prediction` | IDS Prediction |
| `/dataset` | Dataset Analytics |
| `/logs` | System Logs |
| `/settings` | Settings |
| `/login` | Login |

A Not Found page is also included for unsupported routes.
